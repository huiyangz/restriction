# T1S1 增加账户限制

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| tranBranch | java.lang.String | 必填 | | 交易机构号 |
| startDate | java.util.Date | 必填 | | 开始日期 |
| endDate | java.util.Date | 必填 | | 结束日期 |
| baseAcctNo | java.lang.String | 必填 | | 账号 |
| restraintType | java.lang.String | 必填 | | 账户限制类型 |
| runDate | java.util.Date | 必填 | 系统日期表（FM_DATE） | 核心运行日期（同时作为 ST004 交易日期 tranDate 的取值来源） |
| term | java.lang.String | 必填 | | 限制期限 |
| termType | java.lang.String | 必填 | | 周期类型 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| resSeqNo | java.lang.String | 非必填 | 对公存款账户限制表（RB_BUS_RESTRAINTS） | 限制编号（由 ST004 登记账户限制信息时生成并返回；需同步在 ST004 正式定义中补充输出 resSeqNo） |

## 执行步骤

| 序号 | 步骤编号 | 步骤名称 |
|---|---|---|
| 1 | ST001 | 检查限制类型 |
| 2 | ST002 | 检查是否跨法人 |
| 3 | ST003 | 检查增加限制起始日期 |
| 4 | ST004 | 登记账户限制信息 |
