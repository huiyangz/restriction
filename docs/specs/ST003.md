# ST003 检查增加限制起始日期

## 步骤描述

1.检查增加限制起始日期：若上送的{开始日期}小于{系统日期}或者大于{结束日期}，则返回检查结果为“不通过”，否则返回检查结果为“通过”。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| runDate | java.util.Date | 必填 | 系统日期表（FM_DATE） | 核心运行日期 |
| startDate | java.util.Date | 必填 | | 开始日期 |
| endDate | java.util.Date | 必填 | | 结束日期 |
## 输出
| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| checkResult | java.lang.String | 必填 | | 检查结果：通过 / 不通过 |
