# ST003 检查增加限制起始日期

## 步骤描述

1.检查增加限制起始日期：本步骤直接返回 boolean，不另定义输出字段。若上送的{开始日期}小于{系统日期}或者大于{结束日期}，则返回 false（不通过），否则返回 true（通过）。

## 输入

| 字段名 | 类型 | 标记 | 说明 |
|--------|------|------|------|
| runDate | java.util.Date | 必填 | 核心运行日期 |
| startDate | java.util.Date | 必填 | 开始日期 |
| endDate | java.util.Date | 必填 | 结束日期 |
